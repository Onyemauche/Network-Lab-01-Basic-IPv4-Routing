# Cisco Network Labs

A hands-on networking portfolio documenting network design, configuration, verification, and troubleshooting using Cisco networking concepts and simulation tools.

The goal is to build practical networking skills through progressively more advanced labs, from basic IPv4 routing to enterprise networking, security, and network automation.

## Objectives

- Understand IPv4 addressing and subnetting.
- Configure routers and switches using Cisco IOS-style commands.
- Build and troubleshoot switched and routed networks.
- Implement VLANs, trunking, routing protocols, and access control.
- Explore network security, monitoring, and automation.
- Document every lab clearly enough for another person to reproduce it.

## Lab Documentation Standards

Each lab will document, where applicable:

- Problem statement and learning objectives
- Network topology and device inventory
- IP addressing plan
- Device configurations
- Verification commands and expected results
- Troubleshooting scenarios and solutions
- Screenshots and evidence from actual lab tests
- Lessons learned and simulator limitations

## Tools and Environment

- Cisco Packet Tracer for initial network simulation
- Cisco IOS-style command-line configuration
- GitHub for project documentation and portfolio development

Additional simulators and tools will be introduced as the labs become more advanced.

## Project Principles

**Reproducibility:** Network designs and configuration steps should be clear enough for another learner to follow.

**Verification:** Connectivity and configuration claims must be supported by actual test results.

**Troubleshooting:** Labs should demonstrate not only how to configure a network, but also how to identify and resolve faults.

**Technical accuracy:** Device commands and features may vary across models and simulator versions. Any relevant limitations will be documented.
